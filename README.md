# install pygame dlu brok

pastikan  di komputer brok brok semua sudah ada pip dengan membuka terminal dan menjalan kan **pip --version**

jika belum terinstal sebaiknya menginstal python terlebih dahulu di website resmi python https://www.python.org/downloads/.
ini adalah cara termudah untuk menginstal pip.

jika python sudah terinstall, sekarang install library pygame dengan cara:
1. buka terminal di vscode
2. ketik **pip install pygame** jika cara itu tidak bisa coba cara ini **pip3 install pygame**
3. tunggu instalasi sampai selesai dan,
4. jalankan game dan selamat bermain brok

__jika tidak bisa di run__
1. buka kembali terminal di vscode
2. pergi ke direktori file game nya dengan cara ketik di terminal **cd Downloads** dan **cd makanlek**
3. ketik di terminal **python3 game.py** dan,
4. selamat bermain brok
